# ドキュメント作成規約

## 原則

ドキュメントは、**最終的な設計を最初からそう計画していたものとして記述する**。想定読者は検討の経緯を一切知らない新規参画者とし、経緯を知らなければ意味が通じない文を残さない。

想定読者は、検討の経緯を一切知らない新規参画者とする。経緯を知らなければ意味が通じない文を残してはならない。
更新時は差分を追記するのではなく、**その時点の最終形として全面的に書き直す**。

## 書かないもの

* 変更履歴・経緯
* 検討過程
* 会話・会議・レビューへの参照
* 課題管理ツールのID参照
* 未確定であることの但し書き。未確定なら、確定させるか、その項目自体を書かない
* 他ドキュメントへのポインタ。
