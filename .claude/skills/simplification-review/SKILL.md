# 過剰実装レビュー

削れる箇所だけを挙げる。不具合・脆弱性・性能は対象外とし、通常のレビューへ回す。列挙のみを行い、修正は適用しない。生成物は対象としない。

1件1行。`<ファイル>:L<行>: <タグ>: <削るもの>。<代わりに使うもの>。`

* `delete` 到達しないコード、使われていない設定、先回りの機能。代わりはない
* `stdlib` 標準ライブラリにある処理の手書き。関数名を挙げる
* `platform` DB の制約・索引、zod、標準ウィジェットで済む箇所
* `yagni` 実装が1つの抽象、呼び出し元が1つの層。展開する
* `shrink` 同じ振る舞いをより少ない行で書ける箇所。短い形を示す

最後に `net: -N 行削減可能。` を置く。削る箇所がなければ `削る箇所なし。` とだけ書く。
