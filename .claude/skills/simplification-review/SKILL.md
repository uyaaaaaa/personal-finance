# 過剰実装レビュー

削れる箇所だけを探す。差分にとっての最良の結果は、差分が短くなることである。

## 対象

指定がなければ作業ツリーの差分を対象とする。「リポジトリ全体」と指定された場合は、生成物（OpenAPI 仕様、Dart クライアント、マイグレーション SQL）を除いた全ファイルを対象とし、削減の大きい順に並べる。

## 形式

1件1行。`<ファイル>:L<行>: <タグ>: <削るもの>。<代わりに使うもの>。`

| タグ | 対象 | 代わりに使うもの |
|---|---|---|
| `delete` | 到達しないコード、使われていない引数・設定、先回りの機能 | なし（消すだけ） |
| `stdlib` | 標準ライブラリにある処理の手書き | 関数名を挙げる |
| `platform` | プラットフォームが持つ機能のアプリケーションコードでの代替 | DB の制約・索引、zod、Flutter 標準ウィジェットなどを名指しする |
| `yagni` | 実装が1つしかない抽象、呼び出し元が1つの層、誰も変えない設定値 | 呼び出し元に展開する |
| `shrink` | 同じ振る舞いをより少ない行で書ける箇所 | 短い形を示す |

例:

* `server/src/domain/repository.ts:L12: yagni: 実装が1つのインターフェース。2つ目が現れるまで展開する。`
* `server/src/routes/expenses.ts:L40-58: platform: 一意性をハンドラの事前 SELECT で確認している。UNIQUE 制約。`
* `mobile/lib/ui/history/total.dart:L22-31: shrink: 手書きのループで合計。fold 1行。`

## 締め

最後に `net: -N 行削減可能。` を置く。削る箇所がなければ `削る箇所なし。` とだけ書いて止める。

## 境界

* 対象は過剰実装のみとする。不具合・脆弱性・性能は対象外であり、見つけても本レビューでは扱わず、通常のレビューへ回す
* 最小限の検査1つ（`.claude/skills/implementation/SKILL.md`「検査を伴わない実装は未完成」）を削減対象にしない
* 列挙のみを行い、修正を適用しない
